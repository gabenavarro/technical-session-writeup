# Reference Example

A complete, real technical-session write-up — the reference for what this
skill produces. It documents a (fictional) session building the `md2html`
Markdown-to-HTML renderer, so every rule in the skill is demonstrated in a
working document.

**The audit gate passes on this file (exit 0):**

```bash
python3 ../scripts/audit_writeup.py session-writeup-example.md
```

It reports one advisory (Section 3 has no figure — a deliberate omission:
the gate section's point is best made in prose, not a chart).

## Files

```
session-writeup-example.md   the reference write-up
figures/fig-01-*.png         two XY-generated figures
figures/fig-02-*.png
scripts/make_figures.py      the plotting script (also reproduced in
                             Appendix C of the write-up)
```

## What it demonstrates

- The full required structure (TL;DR → appendices).
- Three technical sections, each with Why / Intuitively / Technically passes.
- Two real XY figures (the audit trajectory, and a before/after asset
  comparison), generated by `scripts/make_figures.py`.
- Appendix A with three genuine correction entries; Appendix B glossary;
  Appendix C with the reproducible plotting script and a pinned XY version.

## Regenerate the figures

Requires `xy` (pinned in Appendix C of the write-up):

```bash
pip install xy
python3 scripts/make_figures.py
```

Re-running overwrites `figures/` in place.
